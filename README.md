InovaMobile - Catálogo Industrial Sobre o projeto

Esse projeto foi feito em Flutter como atividade da faculdade.

A ideia é criar um catálogo simples de produtos para a área industrial, inspirado nas empresas e indústrias de Jaraguá do Sul.

O que o aplicativo faz

O aplicativo possui duas telas:

Tela inicial: mostra alguns produtos industriais. Tela de detalhes: mostra mais informações sobre o produto e permite escolher a quantidade.

Também foi utilizado:

Navigator.push() para ir para a tela de detalhes; Navigator.pop() para voltar; StatefulWidget e setState() para alterar a quantidade; Row, Column e Container para organizar a interface. Tecnologias Flutter Dart Demonstração
